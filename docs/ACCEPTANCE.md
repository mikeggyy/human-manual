# 驗收清單
以下全部是「未實作／未驗證」的網站條件。reports/core-tests.txt 只代表參考核心測試結果。

## A. 真實使用流程
- [ ] 新瀏覽器不登入即可開始，8 題各 3 選項，未作答不能前進。
- [ ] 回上一題與改答案正常；換題後鍵盤焦點正確，結果不會多算。
- [ ] 重整保留合法進度；損壞、舊版本、禁止儲存、容量不足時可安全降級。
- [ ] 8 題完成顯示完整角色說明；重測重新計算且與先前流程分離。
- [ ] 6 種結果都有完整文案與畫面，不出現 placeholder、undefined 或文案裁切。
- [ ] 被分享的結果頁不覆蓋訪客自己的進度，也不假稱訪客完成作答。

## B. 分享與圖片
- [ ] 手機與桌機可以真正產生非空 PNG，文字完整、背景與插畫正常。
- [ ] 匯出字體載入、圖片 CORS、長句換行、toBlob 失敗都處理；不把 DOM 字型缺字藏起來。
- [ ] 原生分享受支援時用原生分享，不支援可複製連結／儲存圖片。
- [ ] 使用者取消分享不顯示紅色錯誤；複製失敗提供可選取的完整網址。
- [ ] 分享網址只含版本與角色，不包含原始答案或個資。
- [ ] 在另一個未登入瀏覽器開啟分享連結，直接到對應角色頁，重整不 404。
- [ ] 主站與專案子路徑的資源、favicon、分享 URL 都正確。

## C. 工程、視覺與公開展示
- [ ] npm ci、npm run typecheck、npm run lint、npm run test:unit、npm run build 實際執行。
- [ ] 單元測試覆蓋計分、平手、6,561 路徑、非法答案、儲存／讀取驗證與 share URL。
- [ ] Playwright 覆蓋首頁→8 題→結果→重測，並測上一步修改、reload、未知分享連結及分享 fallback。
- [ ] 檢查 375px、768px、1440px，無橫向溢出／遮擋，主要按鈕可觸及；手機完整結果卡可讀。
- [ ] 鍵盤、radio labels、焦點、標題階層、對比、減少動態效果皆檢查，不宣稱已取得無障礙認證。
- [ ] 桌機與手機截圖經目視檢查，首頁、作答、結果保持同一設計系統。
- [ ] 沒有 console error、失效控制項、假人數、假精準率、假 GitHub／demo 網址。
- [ ] README 用實際截圖與實際測試結果，列出限制及 AI 協作方式。
- [ ] bundle 不含祕密、API token、姓名／聯絡資訊；原圖及字體授權已核對。
- [ ] GitHub owner／repo／可見度與公開授權已確認；授權確定前不 push／啟用 Pages。
- [ ] 發布後親自開啟實際 URL 驗證，不只以 Actions 綠燈宣稱網站正常。

## 人工試玩
找 3 位一般使用者，不教他們介面怎麼操作，觀察能否自己完成並把結果傳給別人。
記錄題目讀不懂、結果不貼切、找不到下一步、圖片不好讀的地方。
這是可用性試玩，不是心理效度研究，也不能用 3 人結果宣稱大眾一定喜歡。
