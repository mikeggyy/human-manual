# 驗收清單
以下依 2026-09-08 本機 production build 的 Edge Chromium 驗證更新；勾選不代表已完成 iOS 實機、所有瀏覽器或真人試玩。公開 CI／部署證據另見 IMPLEMENTATION-PLAN.md。reports/core-tests.txt 只代表原始參考核心測試。

## A. 真實使用流程
- [x] 新瀏覽器不登入即可開始，8 題各 3 選項，未作答不能前進。
- [x] 回上一題與改答案正常；換題後鍵盤焦點正確，結果不會多算。
- [x] 重整保留合法進度；損壞、舊版本、禁止儲存、容量不足時可安全降級。
- [x] 8 題完成顯示完整角色說明；重測重新計算且與先前流程分離。
- [x] 6 種結果都有完整文案與畫面，不出現 placeholder、undefined 或文案裁切。
- [x] 被分享的結果頁不覆蓋訪客自己的進度，也不假稱訪客完成作答。

## B. 分享與圖片
- [x] 桌機瀏覽器在手機尺寸下真正產生六張非空 PNG；逐張目視完整文字、背景及插畫。手機實機另待驗證。
- [x] 匯出字體載入、圖片 CORS、長句換行、toBlob 失敗均有處理；測試覆蓋字型／插畫載入失敗、空 blob 與重試，實際 PNG 字形已目視。
- [x] 原生分享支援／不支援分支已測；不支援可複製連結／儲存圖片。系統分享面板以受控 API 情境驗證，未宣稱手機實機已測。
- [x] 使用者取消分享不顯示紅色錯誤；複製失敗提供可選取的完整網址。
- [x] 分享網址只含版本與角色，不包含原始答案或個資。
- [x] 在新的未登入頁面開啟分享連結，直接到對應角色頁，重整不 404；相同瀏覽器已存答案也不會變成訪客的作答線索。

## 人工試玩
找 3 位一般使用者，不教他們介面怎麼操作，觀察能否自己完成並把結果傳給別人。
記錄題目讀不懂、結果不貼切、找不到下一步、圖片不好讀的地方。
這是可用性試玩，不是心理效度研究，也不能用 3 人結果宣稱大眾一定喜歡。
