# 使用體驗與內容修整

2026-09-08：使用者授權審視現有 UI／UX 與內容後直接修改並發布。沿用 collectible-edition-concept.png 的精裝手冊系統，本次新增功能在既有元件與素材中延伸，不重新生成整套視覺。

## 審視後的決定

- 保存與復原：重整不再中斷作答。首頁依進度提供繼續或重看結果，清除／重測保留頁內確認。異常以短訊息說明，不阻擋當次作答。
- 結果閱讀：章節前的文字分享連結改成明顯的主要按鈕；先閱讀完整基本設定，再看個人線索和生活場景。目錄增加基本設定／作答線索，跳轉同時移動焦點。
- 分享：手机先看到用途與儲存／分享操作，再看完整角色卡；桌機維持預覽與操作兩欄。PNG 真正產生後才提供下載與預覽，不宣稱已存入相簿。
- 內容：18 個生活片段縮為兩句，六角色結尾改用具體生活意象，減少重複安慰或替讀者下結論。原始八題、六角色原文、計分和版本不變。
- 模板語境：訪客看到角色手冊，不呈現個人答案線索；『給你的最後一頁』等本人語境與共享模板分開。

## 比對記錄

已用 view_image 開啟核准概念及本輪 375／1440px production 截圖，並查看首頁、作答、結果、分享與六張實際 PNG。原概念是 1536×1024 的多畫面總覽，不能當成單一實際網頁尺寸；本次以對應區塊比對，另用 320／375／768／1440px 驗證響應式行為。

| 比對點 | 結果與調整 |
| --- | --- |
| 首頁文字 | 保留既有主標、副標及新使用者 CTA；未加回先前移除的資訊列。有進度時增加對應狀態與續答／重看操作，屬本次功能需要。 |
| 版面 | 保留書冊雙欄、角色紙卡、手機單欄。刻意調整結果閱讀順序與手機分享操作位置，避免先看長卡片才找到按鈕。 |
| 色彩與字體 | 延續奶油紙、墨色、暖橘與灰綠；使用既有明體標題、黑體正文、54px 按鈕，不新增外部字型。 |
| 插圖 | 沿用既有原創 atlas 與精裝封面，PNG 使用相同角色；修整圖格邊緣取樣，避免鄰格細線。 |
| 字級／內容 | 原始角色全文完整保留；延伸段落減少冗句。PNG 完整換行，實際檢查六個長短名稱與代表句。 |
| 操作／動態 | 保留 radio、焦點、頁內確認與 reduced motion；首題返回鍵改為準確的『回到首頁』。錯誤訊息與成功訊息使用不同樣式。 |

既有視覺方向已逐項核對，這次刻意調整的介面文案與順序如上；不以功能通過代替實機或所有平台的視覺驗收。

## 驗證邊界

內建瀏覽器實際檢查互動；專案 Playwright 執行 Edge Chromium 的重複流程、尺寸、PNG 下載與受控失敗情境。原生分享的成功／取消／拒絕以可重現的 API 替身測試，不能代表真實手機分享面板或實際傳送給朋友。

瀏覽器行為依據：[Web Share](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/share) 與 [Canvas PNG 輸出](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/toBlob)。公開驗收與實際執行數據見 ../IMPLEMENTATION-PLAN.md。
